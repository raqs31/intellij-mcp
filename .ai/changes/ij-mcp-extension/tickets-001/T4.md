## Goal

A pure Kotlin run store with no IDE types, and an ISO-8601 time formatter, both covered by plain JUnit 4 tests.

## Non-goals

- No IDE types, no service, no listeners (T5).
- No persistence.

## Context

Plan: "Phase 2 > 2. Pure run store and time formatting". Contract, copied:
- `data class TestCounts(total, passed, failed, ignored, other: Int, finished: Boolean)`.
- `data class RunRecord(executionId: Long, name: String, startedAtMillis: Long?, finishedAtMillis: Long?, exitCode: Int?, tests: TestCounts?)`.
- `class RunStore(maxFinished: Int = 50)`:
  - `started(id, name, atMillis)`. A repeated id replaces the record.
  - `terminated(id, exitCode, atMillis)`. It creates a record with `startedAtMillis=null` if the start was not seen.
  - `testsFinished(id, counts)`.
  - `get(id)`.
  - `finished(name: String?, limit: Int)`, newest `finishedAtMillis` first.
- Live records are never evicted. Once there are more than `maxFinished` finished records, the oldest finished record is dropped.
- The store is thread-safe, because listener callbacks can arrive off the EDT.
- `fun formatInstant(millis: Long?): String` returns local ISO-8601 with offset at second precision, for example `2026-11-04T14:03:40+01:00`, or `unknown` for null.

Settled here:
- A finished record is one with `finishedAtMillis != null`. `terminated` on a record with no name (start not seen) needs a name: use `name = ""` unless a record already exists. `testsFinished` on an unknown id is a no-op.
- `formatInstant` uses `ZoneId.systemDefault()` through a parameter with that default, `formatInstant(millis: Long?, zone: ZoneId = ZoneId.systemDefault())`, so the test can pin a zone. Format with `DateTimeFormatter.ISO_OFFSET_DATE_TIME` after truncating to seconds.
- Use one lock (`synchronized`) around a `LinkedHashMap<Long, RunRecord>`.

Tests: there are no tests in the repo yet. Use JUnit 4 (`org.junit.Test`, `org.junit.Assert.assertEquals`), package `pl.mario.intellij.mcp`. One assertion group per clause:
- `RunStoreTest`: eviction at `maxFinished` drops the oldest finished and keeps live runs (use a small `maxFinished`, e.g. 2); `finished` order is newest `finishedAtMillis` first; name filter; `limit`; terminate-without-start gives `startedAtMillis=null`; a repeated `started` replaces the record; `testsFinished` stores counts.
- `TimeFormatTest`: `formatInstant(null) == "unknown"`; a fixed millis in `ZoneOffset.ofHours(1)` gives `2026-11-04T14:03:40+01:00`; sub-second millis are dropped.
