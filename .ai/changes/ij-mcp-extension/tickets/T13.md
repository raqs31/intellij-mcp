## Goal

`list_run_history` lists recent finished runs from the store, newest first, including runs whose Run tab is closed.

## Non-goals

- No persistence; no edits to `RunHistory.kt` or `RunHistoryService.kt`.
- No change to `list_running_configurations` or `stop_run_configuration`.

## Context

Plan: "Phase 5 > 1. list_run_history tool". Read `RunHistory.kt` (T4: `RunStore.finished(name, limit)`, `RunRecord`, `TestCounts`, `formatInstant`) and `RunHistoryService.kt` (T5: the project service).

Contract, copied:
- `list_run_history(configurationName: String? = null, limit: Int = 10)`. Read-only hints. `limit` is clamped to 1..50.
- It returns one line per finished run, newest first: `executionId=…, name=…, state=terminated, exitCode=…, startedAt=…, finishedAt=…, tabOpen=true|false`. When counts exist, the line adds `, tests: total=…, passed=…, failed=…, ignored=…, other=…, finished=…`.
- `tabOpen` comes from `RunContentManager` on the EDT.
- An empty result is `No finished runs recorded since the plugin loaded.`
- The `@McpDescription` says that history is in memory, keeps the last 50 runs, and is cleared on IDE restart.

Settled here:
- `tabOpen` is true when `RunContentManager.getInstance(project).allDescriptors` holds a descriptor with that `executionId`.
- Copy the hint annotations of `list_running_configurations` (`RunControlToolset.kt:30-31`).
- Timestamps use `formatInstant`; a null `exitCode` prints `unknown`.
- If T11 or T8 added a helper that prints a `TestCounts` line, reuse it.
